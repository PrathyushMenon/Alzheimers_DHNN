# multimodalAD Repo Notes

This clone is `D:\ALZ\code\multimodalAD`.

## Important Findings

- `Swin_FOD/main.py` is the training entrypoint. It uses `utils/data_utils.py`.
- The original Swin-FOD loader hard-coded `/ifs/loni/.../data_list_MOCAnocopy.csv`. It was adapted to accept `--json_list data/official_inputs/swin_fod_local.csv` as a CSV manifest while keeping the official model and trainer.
- `Swin_FOD/model.py` includes `get_features(...)`; `Swin_FOD/extract_features_local.py` uses that method for the 64-D penultimate FOD features.
- `ALBEF/train_ADNI.py` is the training entrypoint. It requires `--checkpoint`; this matches the paper's HABLE/pretraining dependency.
- The cloned repo imports `models.model_pretrain3D`, but `ALBEF/models/model_pretrain3D.py` is missing from the clone. Exact ALBEF training cannot run until that official file is restored/provided.
- `ALBEF/dataset/caption_dataset.py` can load JSON annotations through `adni_cls_dataset3d`. Local JSONs are generated by `ALBEF/data/prepare_json_adni_local.py` and `code/11_prepare_official_inputs.py`.
- The original `tabpfn_for_multiclass_classification_contrast_FOD_moca.py` is hard-coded to `/ifs/loni/...`. The exact local pipeline uses `code/05_train_fusion_model.py` instead, with TabPFN only and no fallback classifier.
